# TikTokn-Stuff

This repository contains a small set of captured crypto/debug artifacts related to TikTok app behavior on Android.

The main file, `tiktok_keys.txt`, includes examples of AES encryption operations (`AES/GCM/NoPadding`, `AES/CBC/PKCS5Padding`, `AES/ECB/NoPadding`), hardcoded keys, and ciphertext output collected during analysis.

This is intended as a reference for reverse-engineering or security research only. It is not a production library or application.

Use responsibly and only for authorized testing and educational purposes.

Collected and intercepted with Frida & the latest TikTok Android Version
